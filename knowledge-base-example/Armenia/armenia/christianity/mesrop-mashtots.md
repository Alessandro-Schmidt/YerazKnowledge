# ✍️ Mesrop Mashtots

A monk and scholar (c. 362–440). In **405** he created the Armenian alphabet so that the Bible and the liturgy could be read in Armenian. That was the start of Armenian literature.

## Letters as numbers

The 36 original letters also served as numerals, in four rows of nine:

| Row | Letters | Values |
|---|---|---|
| 1 | Ա … Թ | 1–9 |
| 2 | Ժ … Ղ | 10–90 |
| 3 | Ճ … Ջ | 100–900 |
| 4 | Ռ … Ք | 1000–9000 |

It is an additive system with no zero, like Greek numerals. Every word has a numeric value, which made the alphabet both a writing system and an arithmetic tool → [Number theory](/Mathematics/algebra/number-theory.md).
