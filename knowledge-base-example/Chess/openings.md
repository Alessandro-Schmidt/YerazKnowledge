# 📖 Openings

The first moves of a game. Each line is named and filed in the ECO codes, A00–E99.

## Principles

Control the centre, develop the knights and bishops, castle early, and don't move the same piece twice without a reason.

## Armenian fingerprints

- **Petrosian Variation**, Queen's Indian: 1.d4 Nf6 2.c4 e6 3.Nf3 b6 4.a3. It stops …Bb4 before it can happen: prophylaxis in one move.
- **Petrosian System**, King's Indian: 7.d5. It closes the centre.
